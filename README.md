# ownwash-clone

Full-stack service booking website — Next.js + Django REST + PostgreSQL.

## Applications

- `frontend/` — customer website, local development on port 3000.
- `admin-portal/` — separate administration website, local development on port 3001.
- `partner-portal/` — separate partner website, local development on port 3002.
- `backend/` — shared Django REST API, local development on port 8000.

Partner and admin websites use the same backend and database as the customer
website. See [partner-portal/README.md](./partner-portal/README.md) for standalone
partner deployment and environment configuration.
